# Agent & IDE Integrations

The Hat is agent-native and ships with drop-in configs for all major assistants.

---

## 1. Cursor IDE

The Hat includes `.cursor/rules/the-hat.mdc` automatically scoped to `docs/evals/**/*.md`.

```md
---
description: The Hat Solution Evaluation Framework
globs: docs/evals/**/*.md, docs/evals/*.md
alwaysApply: false
---

# The Hat Framework for Cursor
1. Do not vibe-rank in chat.
2. Execute Phase 1 first (Steps 1-4).
3. 🛑 Pause for human alignment before scoring.
4. Execute Phase 2 (Steps 5-9) after user confirmation.
```

---

## 2. Universal Agent Skill (`SKILL.md`)

Deploy `.agents/skills/the-hat/SKILL.md` to equip any autonomous agent (Antigravity, Claude, Cursor) with The Hat skill.

---

## 3. GitHub Copilot & Claude Code

- **GitHub Copilot:** Add `integrations/copilot/copilot-instructions.md` to `.github/copilot-instructions.md`.
- **Claude Code:** Reference `integrations/claude/the-hat-instructions.md` in `CLAUDE.md`.
