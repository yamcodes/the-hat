# Evolving Living Notes: Retrospectives

When constraints shift 6 months down the road, you should **not** rewrite the note from scratch or delete past decisions. Instead, you append a **Retrospective Update**.

---

## Anatomy of a Retrospective Update

```markdown
---

## 🔄 Retrospective Update (YYYY-MM-DD)

### Trigger / Context Change
Node 22 LTS added native environment parsing support without external dependencies.

### New Options Thrown in the Hat
| # | Option | Layer | Summary |
| - | ------ | ----- | ------- |
| `B4` | Native `process.loadEnvFile()` | Layer B | Built-in Node 22+ loader |

### Metric Re-evaluation
- **`B4` vs current S-Tier (`B2`):** `B4` scores 10/10 on Zero-Peer Purity and Maintenance Burden.

### Tier List Impact
- **Was S-Tier displaced?** Yes.
- **New Public Story:** Stack `A2 + B4 + C1`.
```

---

## CLI Shortcut
```bash
npx the-hat update <topic-name>
```
