# Claude Code / Claude Instructions: The Hat Framework

Whenever evaluating architectural or technical design choices:

- **Follow The Hat 9-Step Loop:**
  1. Name Problem -> 2. Split Composing Layers -> 3. The Hat Inventory -> 4. Fit Metrics -> 5. Prose Eval -> 6. Tier List & Stack -> 7. S/A Usage -> 8. Living Note in `docs/evals/` -> 9. A-Tier Icebox.
- **Checkpoint Rule:** Present Steps 1-4 to the user first. Obtain confirmation on the layers, options in the hat, and metrics before writing the detailed evaluation and tier list.
- **Save Artifacts:** Write evaluations to `docs/evals/<topic>.md` as living documents.
